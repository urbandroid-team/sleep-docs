# Backup & Data Recovery

### 1. My old backup file disappeared after a new sleep track
The app automatically renames old backups (`sleep-export.backup.zip`) to prevent data loss if a new tracking session begins before an import.
*   👉 **Fix:** Open your file manager, locate the backup folder, and rename `sleep-export.backup.zip` back to `sleep-export.zip`. Then use **☰ → Backup → Import data**.

### 2. Can I analyze my raw sleep data on a PC?
**Yes.** Manual exports include a `sleep-export.csv` file inside the `.zip`. You can open this in Excel or Google Sheets. See our [CSV documentation](/devs/csv.html) for field details.

### 3. Restoring data failed, I see error messages
This can be caused by file permissions, a corrupted ZIP, or version mismatches.
*   👉 **Fix:** Reach out to us at `support@urbandroid.org` with a description of the error and your device model. We'll help you recover your data.
